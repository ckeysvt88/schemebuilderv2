# Phase 5 — evidence-gated call options

The game-plan detail now turns a formation's full play list into a short call menu. The current top call remains **Best Overall**. Additional labels appear only when the exact call has an existing authored classification:

- **Quick-Throw Answer** requires an exact quick-game or hard-flat label.
- **QB Control** requires an exact spy, contain or mobile-QB label.
- **Run-Fit Answer** requires the authored inside/outside run-fit flag for that exact coverage name.
- **Deep Help / Protect the Sticks** requires the existing `longOK` classification and excludes pressure calls.
- **Pressure** requires pressure, blitz, fire, shoot, storm or all-out language on the exact call.

The menu is capped at four unique calls. One call may carry more than one role, which avoids repeating the same answer under several headings. The complete formation inventory remains available under **More calls in this formation**.

This phase does not label a call **User-Friendly** and does not infer player assignments or rush counts. Those distinctions remain blocked on verified exact-call play art and user-role data.
