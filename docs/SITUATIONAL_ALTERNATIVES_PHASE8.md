# Phase 8 — situational objectives and alternatives

`Best Overall` remains the top matchup score. `Best For You` now resolves a second question: which supported call best fits the saved defensive user, call priority, and current down-and-distance objective?

- Third-and-long adds a documented preference for the available deep-help / protect-the-sticks answer.
- Third- or fourth-and-short adds a preference for an available run-fit answer, then a smaller preference for the quick-throw answer.
- Base and red-zone contexts do not invent an objective that the current inputs cannot support.

These weights choose among calls already present in the formation. They do not create a play, assignment, spy, contain player, or run fit. The collapsed card always shows both `Best Overall` and `Best For You`, even when they are the same call, and identifies the selected call's purpose.
