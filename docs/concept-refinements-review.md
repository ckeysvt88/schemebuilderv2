# Football concept refinements — review batch 1

Based on main release 97fcf56. Review branch: football-concept-refinements.
No play-art assignments or user inputs changed. No live deployment intended.

## Changes
- Quick Game / Bubble Screens and West Coast remain broad inside/outside threats. Slant / Quick Hitch alone uses inside help without a hard-flat bonus. Overlapping selections produce one quick-game scenario.
- Hard flats improve the outside portion of mixed quick game, but cannot erase limited underneath support on pressure calls.
- Play action evaluates underneath support and a deep cap separately from the vertical ladder. No count-only claim about a particular defender biting on the fake.
- Mobile, dual-threat, and scrambling QB traits describe escape capability. Option / QB Run and triple option evaluate run support without claiming spy or contain solves handoff/keeper/pitch responsibilities. Combined selections retain both concerns without duplicate scenarios.
- Grades remain provisional ordinal heuristics, not measured success percentages. Exact zone roles, blocking numbers, and matchup speed are not inferred from counts.
